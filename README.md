# E-mobility.vehicleportal

Mobile-First Citizen & EV Driver Digital Vehicle Portal for the National E-Mobility Ecosystem.

## 📱 Key Features
- 🚗 **Digital Vehicle Wallet & QR Code Revenue License**
- 💳 **Real-time Traffic Fines & Evidence Snapshot View**
- ⚖️ **Online Dispute Submission & Digital Fine Payment**
- ⚡ **Live EV Charging Station Locator (Plugs, Power & Pricing)**
- 🔋 **Battery SoC Telemetry & Range Estimates**

## 🚀 Local Development
`ash

# Start development server on port 3000
